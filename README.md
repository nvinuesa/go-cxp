# go-cxp

Go implementation of FIDO Credential Exchange Protocol (CXP)

**Status:** 🚧 Under Active Development - MVP Phase

## Overview

This project implements the CXP (Credential Exchange Protocol) component of the FIDO Credential Exchange specification. The CXF (Credential Exchange Format) is implemented in a separate repository: [github.com/nvinuesa/go-cxf](https://github.com/nvinuesa/go-cxf).

## Requirements

- Go 1.26rc1+
